# PEDOT Device Simulation: Lateral Transport in Organic Solar Cells

[中文](README.md) | [English](README.en.md)

A Python model of a two-dimensional network of photovoltaic microcells. It studies lateral collection beyond a local Ag electrode in inverted organic solar cells and area-dependent collection losses in conventional cells with an ITO/PEDOT composite anode. The implementation uses NumPy, SciPy, and Matplotlib.

## Quick start

Python 3.10 or newer is recommended. Run these commands from the repository root:

```bash
python -m venv .venv
# Windows PowerShell: .venv/Scripts/Activate.ps1
# Linux / macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
python forward_main.py
```

`main.py` runs the conductivity sweep for inverted cells with a local Ag electrode. `forward_main.py` compares ordinary AI 4083 with 2 S/cm PEDOT across different square-cell areas and generates composite sheet-resistance curves and a two-dimensional parameter map. Outputs are saved automatically under `results/`, which is excluded from version control. For headless execution, set `MPLBACKEND=Agg`.

Plots currently use Chinese labels. Install a compatible Chinese font, such as Microsoft YaHei or SimHei, and adjust the font list in the entry scripts if necessary. Selecting this English README does not change plot labels.

This is a model for mechanisms and trends. Conductivities are inputs that should be replaced by measurements of your own films. Values transcribed from a supplementary figure below do not yet have a complete bibliographic reference and should not be treated as universal manufacturer specifications. The LaTeX source `docs/simulation_summary.tex` references local result figures; its core-case dashboard is not automatically generated by the current two entry scripts, so those images must be prepared before compiling the report.

The code and documentation are available under the [MIT License](LICENSE).

## Desktop GUI

After installing the dependencies, run `python gui.py` from the repository root. The desktop interface uses Tkinter and embedded Matplotlib plots and requires no browser.

- **Conventional:** enter square side lengths, PEDOT conductivities, thickness, ITO sheet resistance, and nodes per side. View J–V curves, PCE/FF versus area, and an MPP voltage-deviation map.
- **Inverted:** enter square active-region sizes, the central square Ag pad size, conductivities, thickness, and illumination mode. `full` illuminates the entire active region, `ag_only` the Ag-covered region, and `outside_ag` the uncovered region. ITO sheet resistance is not used in this branch.
- **Sheet resistance:** the minimum and maximum supplied conductivities define the horizontal range. Two ITO sheet-resistance endpoints define the vertical range; color shows composite sheet resistance on a logarithmic scale.

Select a row in the Data tab to display its MPP map. Calculation runs in a background thread. Stop takes effect after the current case finishes and preserves completed cases. Export creates a new subdirectory containing parameters in JSON, the current plot in PNG, full summary metrics, per-case J–V CSVs, and MPP spatial CSVs. Mapping mode exports conductivity, ITO sheet resistance, and composite sheet resistance.

Local photovoltaic calibration remains fixed as in the original scripts; the GUI does not independently adjust Jsc, Voc, or FF. J–V plots display 0–0.95 V; exports retain the full computed range. Nodes per side must be 11–301, with at most 60 cases per interactive sweep. The inverted default is 201 nodes, giving approximately 25 µm spacing at 5 mm; compare mesh resolutions before interpreting small collection lengths.

Official Windows Python distributions usually include Tkinter. On Linux, install the system `python3-tk` package if needed. Run backend checks with `python -m unittest discover -s tests -v`.

## Scientific question

The inverted-cell model describes organic solar cells with a local Ag top electrode deposited through a shadow mask. Ag covers only part of a continuous active layer and PEDOT hole-transport layer (HTL). Under uniform illumination, regions outside the Ag pad also generate carriers.

When PEDOT has sufficient in-plane conductivity, holes from those regions can enter PEDOT and travel laterally to the Ag contact. The measured terminal current may therefore originate from an effective collection area larger than the nominal Ag area. This can produce:

- an elevated apparent short-circuit current density when normalized by Ag area;
- longer transport paths for carriers generated farther from the Ag edge;
- voltage-dependent collection losses and local recombination near the maximum power point (MPP), affecting the J–V curve and fill factor (FF).

The central question is how PEDOT conductivity, thickness, and contact geometry jointly determine collection range, terminal J–V behavior, and FF.

## Inverted-cell structure and scope

```text
Local Ag top electrode (defined by a shadow mask)
│
PEDOT HTL (finite in-plane sheet conductance)
│
Active layer (uniform photogeneration, local nonlinear J–V)
│
Continuous bottom electrode / ETL (initially treated as equipotential)
```

The Ag electrode is a continuous local pad, such as a rectangle or circle. It is not a periodic silver grid. When Ag covers the entire active region and its sheet resistance is negligible, lateral potential gradients in PEDOT approach zero. The inverted branch focuses on partial top-electrode coverage.

## Initial parameters and scales

These values provide starting estimates and sweep ranges rather than universal material constants. ZnO properties in particular depend on processing, thickness, defects, and doping.

| Layer / parameter | Initial value or range | Role and interpretation |
|---|---|---|
| ITO thickness | Approximately 150 nm | Needed when explicitly modeling bottom-electrode transport; replace with the actual substrate value. |
| ITO sheet resistance, inverted branch | Approximately 10 Ω/□ | At 150 nm, equivalent bulk conductivity is approximately 6.7 × 10³ S/cm. The initial inverted solver treats this electrode as equipotential. |
| ZnO thickness | 20–50 nm; initial estimate 30 nm | Vertical electron-transport/contact layer. |
| Effective ZnO vertical resistivity | 10²–10⁶ Ω·cm | An engineering sensitivity range, not a tabulated universal constant. Area-specific resistance is resistivity × thickness. Calibrate against measurements. |
| ZnO lateral transport | Neglected initially | The underlying ITO is expected to dominate lateral electron collection. |
| PEDOT thickness | Fixed at 30 nm | All reported sweeps use the experimentally relevant HTL thickness. |
| PEDOT in-plane conductivity | 10⁻⁴–10³ S/cm | Logarithmic sweep; AI 4083 reference: 2.3 × 10⁻³ S/cm. At 30 nm, sheet resistance spans approximately 3.3 × 10⁹–3.3 × 10² Ω/□. |
| Ag thickness | 100 nm | Bulk resistivity 1.59 × 10⁻⁶ Ω·cm implies an ideal sheet resistance of about 0.16 Ω/□. Real films may require a 0.2–1 Ω/□ sensitivity range. |
| Ag area | Defined by the actual shadow mask | Nominal measurement area; distinguish it from the illuminated active-layer area. |

For an ITO thickness expressed in cm:

$$
\sigma_{\mathrm{ITO}}=\frac{1}{R_{\mathrm{sheet,ITO}}t_{\mathrm{ITO}}}.
$$

The initial inverted model treats Ag as a low-resistance, local equipotential contact. PEDOT is the main lateral resistance being investigated. ZnO is more appropriately represented through vertical transport or contact resistance when extending the model.

Record the actual ITO sheet resistance, PEDOT thickness, and mask dimensions before comparing simulations with experiments. Dark/light J–V curves, ZnO thickness series, and conductivity controls can constrain the local photovoltaic and contact parameters.

## Conductivity values for PEDOT:F and AI 4083

The supplied supplementary figure, titled *Supplementary Figure 4: Electrical conductivity of PEDOT:F and PEDOT:PSS films*, uses the transmission-line method (TLM). Ag contacts are separated by `L = n × 1 mm`. A fit of total resistance against `n` gives the slope `R_L = ΔR/Δn`, from which conductivity is calculated using the definitions in that figure:

$$
\sigma=\frac{L}{a d R_L},
$$

where `a` is the channel width and `d` is film thickness. These are in-plane conductivities and can serve as model inputs. Full source metadata remains to be added.

| Film | In-plane conductivity (S/cm) | Relative to AI 4083 | Sheet resistance at 30 nm (Ω/□) |

| PEDOT:F (1:1.96) | 6.2 × 10⁻² | Approximately 27× | 5.38 × 10⁶ |
| PEDOT:F (1:3.33) | 7.4 × 10⁻³ | Approximately 3.2× | 4.50 × 10⁷ |

The generic material default of approximately 3 × 10⁻³ S/cm is a convenient approximation; the sweep reference uses 2.3 × 10⁻³ S/cm. Even the most conductive PEDOT:F formulation in this figure remains a low-conductivity HTL and should be distinguished from high-conductivity PEDOT:PSS formulations.

At 30 nm, that PEDOT:F formulation still has a sheet resistance of about 5.4 MΩ/□. If experiments show millimeter-scale collection beyond Ag, also examine film thickness, leakage, edge contacts, and the definition of the nominal area.

## Inverted-cell conductivity sweep at 30 nm

`main.py` sweeps 10⁻⁴–10³ S/cm at 0.25-decade spacing. It explicitly includes the five material values above and the conductivity points `0.1, 0.3, 1, 2, 3, 10, 30, 100 S/cm`. Each conductivity uses 61 terminal voltages from 0 to 1.10 V, with collection diagnostics at short circuit and MPP.

The Ag-only illuminated reference is calibrated to `Jsc = 25 mA/cm²`, `Voc = 0.900 V`, and `FF = 0.770`. With ideality factor `n = 1.5`, the calibrated shunt resistance is `466.15 Ω·cm²` and `J0 ≈ 1.870 × 10⁻⁹ mA/cm²`. The node-based Ag-area integration is corrected through `Jph = 24.3865 mA/cm²` so that the nominal-area Ag-only reference gives exactly `25.000 mA/cm²`.

The mesh uses 40 nodes/mm, corresponding to approximately 25 µm spacing. Collection lengths below this scale are not quantitatively resolved and require refinement.

For a 5 mm × 5 mm continuous active region with a central 2 mm × 2 mm Ag pad under uniform illumination, representative results are:

## Physical assumptions and governing equations

1. The active region is uniformly illuminated.
2. PEDOT thickness and in-plane conductivity are uniform.
3. Each planar element is a local photovoltaic microcell represented by a photocurrent source, diode recombination, and shunt leakage.
4. Ag provides a local vertical contact. Uncovered regions retain photogeneration and lateral PEDOT transport.
5. The bottom electrode is equipotential in the initial inverted model.

PEDOT sheet conductance and sheet resistance are:

$$
G_{\mathrm{sheet}}=\sigma_{\parallel}t_{\mathrm{PEDOT}},\qquad
R_{\mathrm{sheet}}=\frac{1}{\sigma_{\parallel}t_{\mathrm{PEDOT}}}.
$$

The local microcell follows:

$$
J_{\mathrm{local}}(V)=J_{\mathrm{ph}}
-J_0\left[\exp\left(\frac{qV}{nkT}\right)-1\right]
-\frac{V}{R_{\mathrm{sh}}}.
$$

The in-plane continuity equation is:

$$
\nabla\cdot\left(G_{\mathrm{sheet}}\nabla V_{\mathrm{PEDOT}}\right)
+J_{\mathrm{local}}\left(V_{\mathrm{PEDOT}}-V_{\mathrm{bottom}}\right)=0.
$$

Neighboring nodes form a sheet-resistor network coupled to the nonlinear local J–V law. Ag contact nodes impose a potential or finite contact resistance. Free edges have zero normal lateral current. The solver uses damped Newton iterations; voltage sweeps produce terminal J–V curves.

## Area normalization

The inverted branch distinguishes:

$$
J_{\mathrm{Ag}}=\frac{I_{\mathrm{terminal}}}{A_{\mathrm{Ag}}},\qquad
J_{\mathrm{active}}=\frac{I_{\mathrm{terminal}}}{A_{\mathrm{active}}}.
$$

- `A_ag`: actual Ag-covered area, often used as the nominal measurement area.
- `A_active`: illuminated continuous active-layer area.
- `A_effective`: voltage-dependent collection diagnostic derived from local collection efficiency.

Jsc and PCE depend on the normalization area. Voc and FF do not. If collection extends beyond Ag, Ag-normalized Jsc can increase without a corresponding increase in power conversion per unit illuminated area.

## Conventional cells: ITO/PEDOT/active layer/PDINN/Ag

This branch models `ITO / PEDOT (30 nm) / active layer / PDINN / Ag`. A continuous Ag cathode covers the whole square cell. Illuminated area, Ag area, and device area are equal, so current density and PCE use the same full-cell area.

### Boundary conditions and composite anode

- Square side lengths: 1, 2, 5, 10, 15, and 20 mm, corresponding to 1–400 mm².
- ITO sheet resistance: 15 Ω/□.
- Ideal anode contact along the entire `x = 0` edge; the other three edges have zero normal current.
- The continuous Ag cathode is equipotential. PDINN in-plane conduction is neglected.
- ITO and PEDOT share the same local potential under ideal interfacial contact and provide parallel lateral conduction paths.
- Local photovoltaic behavior is calibrated to approximately `Jsc = 25 mA/cm²`, `Voc = 0.900 V`, and `FF ≈ 0.770` without lateral voltage loss. Node-area normalization is corrected.

The composite anode follows:

$$
G_{\mathrm{anode}}=\frac{1}{R_{\mathrm{sheet,ITO}}}
+\sigma_{\mathrm{PEDOT}}t_{\mathrm{PEDOT}},\qquad
R_{\mathrm{sheet,anode}}=G_{\mathrm{anode}}^{-1}.
$$

`analysis/forward_edge_contact.py` reuses the nonlinear network solver, interpreting its contact mask as the external ITO edge contact rather than a local Ag pad.

### AI 4083 versus 2 S/cm PEDOT

At 30 nm, the conductivity required for PEDOT sheet conductance to equal that of 15 Ω/□ ITO is:

$$
\sigma_{\mathrm{PEDOT,match}}
=\frac{1}{15\times3\times10^{-6}}
\approx 2.22\times10^4\ \mathrm{S/cm}.
$$

The two simulated conductivities are 2.3 × 10⁻³ S/cm for AI 4083 and 2 S/cm for the comparison PEDOT. Their PEDOT sheet resistances are approximately 1.45 × 10⁸ and 1.67 × 10⁵ Ω/□, respectively. The composite anode sheet resistance changes only from 14.999998 to 14.998650 Ω/□.

|---:|---:|---:|---:|---:|
| 1 | 1 | 17.335513 | 17.335515 | 0.000002 |
| 2 | 4 | 17.269219 | 17.269226 | 0.000008 |
| 5 | 25 | 16.699163 | 16.699222 | 0.000059 |
| 10 | 100 | 14.610010 | 14.610269 | 0.000259 |
| 15 | 225 | 11.396983 | 11.397417 | 0.000434 |
| 20 | 400 | 8.718374 | 8.718756 | 0.000382 |

The curves overlap at ordinary plotting scales because the predicted difference is extremely small. At 10 mm × 10 mm, the corresponding FF values are 0.656352 and 0.656363. The major area-dependent loss arises from the ITO sheet resistance. The extra decimal places show the computed comparison; they do not imply equivalent experimental or mesh-converged accuracy.

Under these assumptions, increasing PEDOT conductivity to 2 S/cm provides negligible lateral shunting of 15 Ω/□ ITO. Matching ITO conductance requires approximately 2.2 × 10⁴ S/cm; appreciable benefits can begin below that matching value. Lower ITO sheet resistance or additional edge/metal contacts are alternative ways to reduce collection losses.

Run `python forward_main.py`. Files are saved in `results/forward_edge_contact/`:

- `forward_size_scan.csv`: size, conductivity, sheet resistances, Jsc, Voc, FF, and PCE;
- `forward_size_scan_summary.png`: PCE, FF, and Jsc versus area;
- `forward_size_scan_heatmap.png`: PCE versus size and conductivity;
- `forward_10mm_potential_comparison.png`: MPP junction-voltage deviation maps for AI 4083 and 2 S/cm PEDOT in a 10 mm square cell;
- `pedot_ito_composite_sheet_resistance.png`: composite sheet resistance and its reduction versus PEDOT conductivity at fixed 15 Ω/□ ITO;
- `pedot_ito_composite_sheet_resistance_map.png`: PEDOT conductivity versus ITO sheet resistance, with color representing composite sheet resistance for 30 nm PEDOT.

The sheet-resistance map covers PEDOT conductivities from 10⁻⁴ to 10⁶ S/cm and ITO sheet resistances from 1 to 100 Ω/□. It is an analytical parameter map, not a claim that all plotted conductivities are achievable in PEDOT films.

ITO/PEDOT interface resistance, Ag lateral voltage loss, optical parasitic absorption, and edge-contact resistance are neglected. The ideal-contact approximation estimates the available parallel-conduction benefit. For quantitative experimental fitting, introduce measured contact geometry/resistance and, where needed, separate coupled ITO and PEDOT sheet networks.
